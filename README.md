Select pypi-prod and use the configuration that the page generates.

For a Windows local environment, your pip configuration is normally:

%APPDATA%\pip\pip.ini

rather than the Linux path ~/.pip/pip.conf shown on that page.

The structure should be:

[global]
index-url = <THE pypi-prod URL GENERATED BY YOUR INTERNAL PAGE>

Then test:

python -m pip config list

and:

python -m pip install pytest

or, if you are inside the RPR venv:

.\venv\Scripts\python.exe -m pip install pytest
