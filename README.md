
Open Citi Artifactory in your browser.
Log in normally.
Click your username in the top-right → Set Me Up.
Select PyPI.
Select the repository you are entitled to — probably pypi-dev based on your current configuration.
Let Artifactory generate the pip configuration. Do not manually construct the username/token URL.
On UNIX, create your personal pip configuration:
mkdir -p ~/.pip
chmod 700 ~/.pip
vi ~/.pip/pip.conf

Paste exactly the block generated by Artifactory, save and exit.

Then:

chmod 600 ~/.pip/pip.conf

Do not send me a screenshot of that file because it may contain your API key/token.

Now go back to RPR:

cd /home/ak54743/Rapid_Portfolio_Review_AI_UNIX_PACKAGE
. .venv/bin/activate

Confirm that pip now sees your user configuration:

python -m pip config debug

Then make one small authentication test:

python -m pip install fastapi
